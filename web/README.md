# ProxyPilot 浏览器扩展

ProxyPilot 的浏览器扩展版本（Chrome / Edge 等 Chromium 内核浏览器，Manifest V3）。与桌面版共享同一套情景模型：固定代理、PAC 脚本、自动切换规则，直接在浏览器内生效，无需修改系统代理。

## 安装（开发者模式加载）

1. 打开 `chrome://extensions`（Edge 为 `edge://extensions`）
2. 打开右上角「开发者模式」
3. 点击「加载已解压的扩展程序」，选择本仓库的 `web/` 文件夹
4. 工具栏出现 ProxyPilot 图标，点击弹出快速切换面板

## 功能

- 情景模式：直接连接、跟随系统、固定代理（HTTP / HTTPS / SOCKS4 / SOCKS5，支持认证）、PAC 脚本（远程 URL 或内置脚本）、自动切换（主机 / 网址通配符与正则规则）
- 弹窗快速切换，数字键 1-9 直达；首页可对当前标签页域名一键添加分流规则
- 图标角标实时显示当前情景名称与颜色
- 代理服务器认证自动应答（webRequestAuthProvider）
- 设置页管理情景、规则、外观（深浅色 / 中英双语）、配置导入导出
- 桌面版导出的 JSON 备份可直接导入

## 与桌面版的对应关系

| 桌面版 | 扩展版 |
| --- | --- |
| Windows 注册表写入系统 PAC | chrome.proxy API（浏览器内生效） |
| 本地 PAC 服务 127.0.0.1:17777 | PAC 脚本数据直接注入 |
| 「系统代理」恢复注册表备份 | 「跟随系统」交还浏览器默认（继承系统代理） |
| 托盘菜单 | 工具栏弹窗 + 图标角标 |
| 卸载时恢复系统代理 | 浏览器在扩展移除时自动还原其代理设置 |

## 桌面版运行时自动让位

chrome.proxy 设置一旦被本扩展写入，浏览器就会完全无视系统代理。为了让「所有浏览器走桌面版系统 PAC」成立，扩展引擎会探测桌面版的状态端点（http://127.0.0.1:17777/proxypilot.state）：

- 桌面版运行中：扩展清除自己的 chrome.proxy 设置，角标显示 DT，弹窗提示「桌面版已接管」，浏览器跟随桌面版的系统 PAC；此时在扩展里切换情景不会生效，请到桌面版切换
- 桌面版退出后：扩展在一分钟内的下一次巡检中自动恢复接管，按扩展自己的情景继续工作

其他带代理权限的扩展（SwitchyOmega、SetupVPN 等）同样会覆盖系统代理；如果桌面版在某个浏览器里不生效，先停用它们再测试。

## 与桌面版互相同步规则

两版同时运行时（扩展处于让位状态），弹窗会显示「从桌面版同步规则」按钮，点击后通过桌面版本地服务（/proxypilot.rules）把桌面版的情景与规则整体导入扩展；本地设置（主题、语言）与订阅保留。扩展同时每分钟向桌面版发送一次心跳（/proxypilot.extension，携带当前情景），桌面版主窗口检测到后也会显示「同步扩展版规则」按钮，方向相反、语义相同。

## Edge 把扩展自动关闭了？

扩展没有任何自我关闭的逻辑；如果 Edge 在过一段时间后把它关了，那是 Edge 对「开发者加载 / 未打包扩展」的安全机制：Edge 更新后或周期性地以「为帮助保护你的设备，已关闭来自未知来源的扩展」为由关闭旁加载扩展。确认与解决：

- 打开 `edge://extensions`，确认左下角「**开发人员模式**」开关为开。它一旦被关掉（Edge 更新有时会顺带关闭），所有未打包扩展都会被禁用；重新打开后把 ProxyPilot 的开关再打开即可
- `edge://settings` 搜索「扩展」，打开「**允许来自其他商店的扩展**」
- 被关闭后重新启用即可恢复，配置存在 chrome.storage 里不会丢失；角标显示 DT 是桌面版接管的正常状态，不是被禁用
- 确认加载的文件夹仍是本仓库的 `web/` 目录（卡片上应显示版本 1.2.0）；若目录被移动或删除，Edge 会把扩展标为损坏
- 公司管理的电脑可能由组策略禁用外部扩展，可在 `edge://policy` 搜索 `BlockExternalExtensions` 或 `ExtensionInstallBlocklist` 确认
## 权限说明

- proxy / storage — 应用情景与保存配置
- alarms — 定时拉取订阅更新（浏览器重启后闹钟仍在）
- tabs — 读取当前标签页域名，用于「当前站点快速分流」
- webRequest + webRequestAuthProvider — 代理服务器要求认证时自动提交凭据
- host_permissions (<all_urls>) — MV3 规定 webRequest 事件只对已声明 host 权限的 URL 派发；代理认证 challenge 可能出现在任意网址上，因此需要全站权限

## 结构

- background/engine.js — 代理引擎：情景到 chrome.proxy 的映射、认证应答、消息枢纽
- lib/ — 与桌面版共享的模型、PAC 生成、站点匹配、i18n（改桌面端对应文件后运行 npm run sync:web 同步；npm run test:web 会检查两边是否一致）
- popup/ — 快速切换弹窗
- options/ — 设置页
